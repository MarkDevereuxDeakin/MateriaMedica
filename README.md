# Japanese Kampo and Botanical Toxins

An educational web application showcasing a curated database of **Japanese Kampo medicinal herbs** and **botanical toxins**.  
Designed for healthcare professionals, herbalists, researchers, and students interested in traditional Japanese medicine and toxicology.

## 🌿 Features

- Searchable table of Japanese Kampo herbs
- Searchable table of toxic plants and phytotoxins
- Pagination for efficient browsing
- Responsive design (mobile/tablet/desktop)
- Clean, botanical-inspired aesthetic
- MongoDB backend for data management
- REST API for Kampo and Toxicology data
- Admin CRUD operations (add, edit, delete entries) *(if enabled)*

## 🔧 Tech Stack

- **Frontend**: React, React Router, React Paginate, CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB (local or Atlas)
- **Design**: Botanical parchment theme with modern navigation
